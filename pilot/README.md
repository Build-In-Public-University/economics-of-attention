# Pilot deploy surface

This directory is the clean deployment boundary for the public pilot. It contains no credentials and no raw participant data.

- `site/` is generated by `scripts/build_pilot.py` from the canonical game artifacts.
- `functions/api/events.js` accepts bounded anonymous funnel events.
- `schema.sql` is the D1 schema.
- The event endpoint stores run-level outcomes without names, emails, IP addresses, free text, or answer selections.

The Pages project and D1 database are intentionally separate external resources and must be read back after creation/deployment.
